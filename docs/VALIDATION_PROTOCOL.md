FTRT VALIDATION PROTOCOL

Objetivo
---------
Evaluar si las variables geométricas contienen información estadísticamente asociada a indicadores de actividad solar.

Serie geométrica
----------------
Fuente:
    DE440s + Skyfield

Periodo:
    2020-01-01 → 2026-12-31

Variables
----------
lambda_max
energia_resonancia
coherencia_espectral
entropia_espectral
entropia_fase
concentracion_fase

Serie observacional
-------------------
SILSO Daily Sunspot Number

Análisis previstos
------------------
• Pearson
• Spearman
• Cross-correlation
• Retardos ±60 días
• Bootstrap
• Permutation test

Criterios
----------
No se modificará la definición de las variables después de observar los resultados.
