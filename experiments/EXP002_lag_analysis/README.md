Evaluar la correlación entre las variables geométricas del FTRT y el
Sunspot Number (SILSO) considerando desfases temporales.

- lambda_min
- energia_resonancia
- coherencia_espectral
- entropia_espectral
- estados_fase
- entropia_fase
